# Shadowverse 戦績トラッカー（PWA版 v6.0）

シャドウバース Worlds Beyond の戦績管理アプリ。Android/iPhone のホーム画面に追加してオフラインで使えます。

## 機能一覧

- 7クラス対応（エルフ／ロイヤル／ウィッチ／ドラゴン／ナイトメア／ビショップ／ネメシス）
- シリーズ機能（必須）— デッキ・相手デッキタイプの候補はシリーズごとに分離
- 先攻／後攻の記録、デッキのスクリーンショット添付
- 記録の編集・削除
- 統計：直近5/10/20戦、先後別、デッキ別（タップで相手クラス×デッキタイプのマッチアップ）、対戦相手別（タップで詳細）
- デッキタブ：シリーズ統合フィルタ（登録先と一覧が連動）＋ ▲▼ で並び替え
- CSV出力・取り込み（追加／置き換え、重複は自動スキップ）
- オフライン対応（PWA）

## 同梱ファイル

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| manifest.json | PWAマニフェスト |
| sw.js | Service Worker |
| icon-192.png / icon-512.png / icon-maskable.png | アプリアイコン |

## セットアップ（GitHub Pages）

1. GitHubで新規リポジトリを作成（Public）
2. 全ファイルをアップロード
3. Settings → Pages → main ブランチを選択
4. 発行されたURLをスマホのChromeで開き「︙」→「ホーム画面に追加」

※ 以前と同じURL（同じリポジトリ名）で公開すると、ブラウザに残っているデータがあればそのまま読み込まれます。

## データについて

- localStorage に保存（キー：sv4-m / sv4-d / sv4-s ※旧版と同じ）
- 旧版で出力したCSVはそのまま取り込めます
- 定期的にCSV出力でバックアップ推奨
